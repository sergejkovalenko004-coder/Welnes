# Wellness — сайт курса

Статический адаптивный сайт на HTML, CSS и JavaScript. Не требует Node.js, сборки или базы данных.

## Структура

- `index.html` — главная страница
- `assets/css/styles.css` — стили
- `assets/js/main.js` — интерактивность
- `documents/` — место для юридических документов
- `.github/workflows/` — место для CI/CD при необходимости

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация

Проект можно разместить на обычном веб-хостинге TimeWeb как статический сайт: загрузить содержимое репозитория в корневую папку сайта (обычно `public_html`) либо настроить автоматический деплой из GitHub, если выбранный тариф и панель TimeWeb поддерживают такой способ.

## Перед запуском

1. Уточнить финальное название курса, описание и цену.
2. Заменить демонстрационную кнопку покупки на реальную платёжную интеграцию.
3. Подготовить и проверить оферту и политику конфиденциальности.
4. Указать рабочий email поддержки и реквизиты ИП.
5. Подключить HTTPS и проверить сайт на мобильных устройствах.
